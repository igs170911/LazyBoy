## 第一次設定模型

打開「設定 → 模型」，完成三件事：

1. **選擇供應商**：內建 OpenRouter、Anthropic、OpenAI、DeepSeek、Gemini、OpenCode 等 40 多個 Hermes 支援的供應商。清單外的服務請選「自訂 OpenAI 相容服務…」，並填寫基底網址（通常以 `/v1` 結尾）。
2. **貼上 API key**：服務網址會自動帶入；離開金鑰欄位時會自動載入模型清單。
3. **選擇模型**：LazyBoy 會用 Chat Completions、Responses、Anthropic Messages 三種 API 介面各送一個極小的請求，找出模型實際可用的介面，並顯示「✓ 可以使用」或無法使用的原因（金鑰錯誤、模型下架、供應商忙碌）。無法使用的模型會排在清單最後。

供應商金鑰只保存在 LazyBoy 服務端；Bot 的電腦只拿到自己的連線憑證，看不到金鑰。

模型設定的變更從下一次工作開始生效。工作因模型問題失敗時，對話會先用中文說明原因與處理方式，原始錯誤附在下方。每個 Bot 也可以在自己的設定中指定不同的供應商與模型；沒有指定時使用全域預設值。

## Bot 與對話

- **建立 Bot**：側欄的「＋」（Ctrl+Alt+N）打開「新增」，可以輸入名字直接建立、從「認識你未來的隊友」範本開始（幕僚長、選品研究員、社群小編、業務開發等），或勾選 2 到 10 個 Bot 開群組對話；也可以「建立團隊」，一次建好主管與成員。
- **人設與外觀**：每個 Bot 有自己的名字、職稱、人設、回覆風格與頭像（十種造型，表情會跟著 Bot 的狀態變化：收到、工作中、等待、完成、失敗、休息）。頭像也可以上傳圖片裁切，或在「AI 產生」分頁描述一句話請生圖模型畫：有填金鑰的供應商裡能畫圖的模型都會列出（例如 xAI 的 grok-imagine），其他模型在「設定 → 模型 → 進階設定」勾選「產生圖片」後也會出現。
- **交辦工作**：在對話中描述要做的事。每個 Bot 同時只執行一個工作；工作進行中送出的訊息會當成補充，直接交給正在工作的 Hermes。帶圖片的補充會排到下一輪，讓圖片完整附上。
- **工作進度**：進行中顯示一行「思考中」與目前步驟，以及 Bot 自己列的計畫。完成後，過程收在答案上方的「已完成 · N 個步驟」，展開可看計畫與每一步（失敗的步驟標紅）；用到網路資料時，答案下方會列出「來源」。重新整理頁面後仍會保留。
- **停止**：按停止會結束這次工作，檔案與對話都會保留。Bot 超過 15 分鐘沒有任何動靜（有工具在執行時為 40 分鐘）會自動停止並標示未完成。
- **對話串**：同一個 Bot 可以開多個對話串。標題旁的「新對話」建立新串，上方分頁切換。每串對應一個獨立的 Hermes session，有自己的上下文與標題（Hermes 會自動命名，也可以手動改名）；記憶、技能、檔案與電腦則共用。一台電腦一次只做一件事，其他對話串的訊息會排隊。
- **回覆格式**：回答以聊天適用的 Markdown 呈現，支援標題、清單、勾選清單、表格、引用與程式碼區塊（語法上色、可複製）。
- **檔案**：工作產出的檔案放在 Bot 的 `/workspace`。答案下方列出最重要的 3 個檔案；右側「檔案」面板可以瀏覽全部檔案，預設隱藏建置輸出、快取與 log。Office 文件、PDF、圖片與壓縮檔可以直接在網頁預覽。
- **提問與審批**：Hermes 需要確認時，會在輸入框上方顯示卡片，支援多題、複選、允許操作與秘密輸入。秘密答案不會寫進對話或事件紀錄。Hermes 允許時，審批卡片會多一個「一律允許」選項。
- **先問我**：Bot 設定的「這些事先問我」可勾選寄出或傳送訊息、公開發佈、付款購買、刪除資料。勾選的動作，Bot 會先說明並等你同意；不是你發起的工作（定時任務、隊友交辦）會送到側欄最上方的「待你核定」，不會過期，你核准後才執行。預設都不勾選。
- **回覆與表情**：每則回答旁有「回覆這則訊息」（送出時一起引用）、「表情回應」（👍 ❤️ 😂 🎉 🙏 👀）、「朗讀」與「複製」。在桌機選取一段文字會出現「引用」。
- **草稿**：還沒送出的內容（包含群組對話）在切換對話與重新整理後會保留，關閉分頁後清除。

## Bot 的電腦

每個 Bot 都有一台在本機 Docker 中執行的 Linux 桌面，Bot 可以操作桌面、使用瀏覽器、執行指令與管理檔案。電腦不會掛載主機的工作目錄或 Docker socket。

- **看著它做或接手**：點對話標題列的「電腦」打開面板。你和 Bot 操作同一個 Chromium；需要登入、驗證碼、防機器人驗證，或有自動化點不動的按鈕時，Bot 會請你在面板做那一步，完成後按「交還給 Bot」，它接著把整件事做完，不會把整件工作丟回給你。不同 Bot 的登入彼此獨立。
- **桌面工具**：Debian 13 的 XFCE 桌面（Orchis 深色主題），Chromium 與選單都是繁體中文。工作列有「瀏覽器」、「終端機」與「檔案」（Thunar，開在 `/workspace`）。文字與程式碼用 Mousepad 開啟，圖片用 Ristretto，Word、Excel、PowerPoint 用 LibreOffice（繁體中文介面），PDF 與網頁用瀏覽器，壓縮檔用 Xarchiver。
- **資源限制**：每台電腦預設最多使用 2 CPU、3 GB 記憶體與 512 MB shared memory。電腦面板放到背景 15 秒後會暫停畫面串流，切回時立即恢復；畫面斷線會自動重連。
- **電腦選項**：面板右上的選單可以重新連線、在新分頁開啟、重新啟動電腦，或「更新電腦環境」以套用新版映像。
- **分頁自動收拾**：Bot 做完手上的工作、沒有其他排隊的事時，瀏覽器只留最後用的那個分頁，其他全部關閉（你自己在它電腦上開的分頁也會一起關）。登入狀態存在 cookie 裡，不受影響。
- **寫程式**：寫程式、建專案、修 bug 時，Bot 會用內建的 `grok-build` 技能交給 Grok Build CLI（`grok`），自行驗收後回報摘要。第一次使用前，在該 Bot 的「電腦 → 終端機」執行 `grok login`。
- **深入研究**：需要比較多個來源時，Bot 會用內建的 `deep-research` 技能：先列計畫，用子 agent 平行查證、交叉比對，再把附來源的報告寫進 `/workspace/reports/`。

## 團隊：Bot 互傳訊息與群組對話

Bot 之間可以像團隊一樣分工：

- **互傳訊息**：Bot 需要隊友的專長時，會用 `message_bot` 工具傳送請求、提問或通知。對方在自己的對話中處理，回答會自動送回原本的對話，由發起的 Bot 整合後回報你。過程是非同步的，不會卡住等待。你也可以直接交代「去問某某」。訊息或回報裡提到的檔案（`/workspace/…`）會自動複製到對方電腦的 `/workspace/from/寄件者/`，在對方的對話裡點得開（每則最多 10 個、50 MB）；轉手的檔案也會一路跟著走，對方原本就有的同一份檔案不會重複複製。被交辦的 Bot 如果再把工作派給其他隊友，不會先回一句「已派工」交差，而是等隊友的結果都回來、整合後，才把最終結果送回原交辦人。
- **事件列**：發起方顯示「已傳請求給某某」，收件方顯示「來自某某的請求／回覆」。點開可看內容；「查看與某某的所有往來」列出兩個 Bot 之間的完整訊息。
- **隊友名單**：每個 Bot 的人設會附上其他 Bot 的名字、職稱與介紹，作為分工參考。設為「主要 Bot」（側欄名字旁有星號）的 Bot 負責協調與彙整；其他 Bot 不確定該找誰時會交給它。
- **群組對話**：選 2 到 10 個 Bot 開群組。用 `@名字` 指定誰負責下一步；沒有點名時，每位成員自行判斷是否回答，不需要時保持沉默；`@everyone` 點名所有人。群組可以加入檔案，檔案會放到每位成員電腦的同一個位置。
- **群組不顯示的內容**：審批、登入、補充資料等提問出現在該 Bot 自己的對話中，群組只顯示「某某在自己的對話等你回覆」。
- **防止失控**：你的訊息永遠排在 Bot 傳來的訊息前面；同一串 Bot 往來最多 6 次，之後要先回報你；群組中一則訊息之後最多 4 輪 Bot 互相點名。停止一個 Bot 會一併停止它交給其他 Bot 的工作。
- **Bot 自己組隊**：Bot 可以用 `start_group_chat` 開群組、用 `post_to_group` 在群組發言；在你同意後用 `create_bot` 建立新的 helper Bot（每個 Bot 一天最多 3 個，總數上限 50），或用 `update_my_profile` 更新自己的職稱與頭像。
- **費用**：每一次 Bot 回覆都會用到模型，包含 Bot 之間的訊息與群組回覆。成員越少、點名越明確，花費越少。

### 組織架構、團隊與核定

- **組織架構**（側欄底部）：樹狀列出誰向誰報告、每個 Bot 正在做什麼。點一個 Bot 可以改它「向誰報告」，或開關「團隊管理權限」；同樣的設定也在 Bot 設定裡。
- **主管看板**：有下屬的 Bot 會用 `team_status` 查看底下每個人的狀態、目前的工作與來源、排隊數、最近一週完成的事，不必傳訊息追問，再整理向上回報。
- **建立團隊**：「新增 → 建立團隊」，從工程團隊、公司組織、行銷團隊範本或自訂開始，一次建立主管與成員、同名側欄分區，可選擇開團隊群組對話與主管每日回報。
- **讓 Bot 替你管團隊**：開啟某個 Bot 的「團隊管理權限」後，可以直接說「幫我建一個工程團隊，要有前端、後端、QA、DBA」。它會先確認名單，再用 `create_team` 建立；也能用 `update_bot` 調整其他 Bot 的職稱、人設、報告對象與分區。有這個權限的 Bot 一天最多建立 20 個 Bot，不能刪除 Bot。
- **待你核定**：組織架構裡的「只有你能決定的事」（預設新商品定價、新增支出、簽約、上架、重要對客承諾）遇到時，Bot 用 `request_approval` 送到側欄最上方的「待你核定」，會跳通知、不會過期。你按核准或退回（可附備註），結果以你的名義回到那個 Bot 的對話；主管或隊友說可以都不算數。

## 側欄與日常操作

- **右鍵選單**：在 Bot 上按右鍵（手機長按）可以釘選、從側欄隱藏、標為未讀、設為主要 Bot、複製 Bot、關閉通知、分享、存成範本、移到分區、清除對話或刪除。
- **分區**：Bot 可以拖到其他分區、「已釘選」或「已隱藏」；分區名稱也能拖曳排序。
- **複製 Bot**：產生「某某 副本」，帶外觀、人設、模型、技能、專用串接與定時任務（定時任務會先暫停），不帶對話、記憶與檔案。
- **未讀**：有新動靜的 Bot 或群組會顯示藍點；未讀與等你回覆的數量也會顯示在分頁標題與 App 圖示上。
- **通知**：在「設定 → 一般 → 通知」開啟後，LazyBoy 在背景時，Bot 完成或等你回覆會跳出系統通知。
- **外觀**：在「設定 → 一般 → 外觀」選擇淺色、深色或跟隨系統。強調色預設為黑白，也可以改成紫色。系統開啟「減少動態效果」時不播放進場動畫。
- **手機**：手機上 Bot 清單與對話分頁顯示。安裝到主畫面後可當作 App 使用，從左側邊緣滑動即可返回；側欄底部只留「設定」，Bot 範本、連接應用程式與組織架構收在「更多」選單裡；Android 上還能從其他 App 的「分享」選單把文字與連結送進 LazyBoy。

## 搜尋、快速鍵與語音

- **搜尋與指令**：Ctrl+K（Mac 為 ⌘K）打開搜尋面板，可以找 Bot、群組、所有對話中的訊息、檔案與定時任務；選擇訊息會跳到原位置。沒有輸入時列出最近的對話與常用動作。
- **對話內尋找**：Ctrl+F 在目前對話中標示所有結果，Enter／Shift+Enter 切換。
- **鍵盤快速鍵**：Ctrl+/ 列出全部，包括 Ctrl+I 回到輸入框、Ctrl+D 語音輸入、Ctrl+B 精簡側欄、Alt+↑／↓ 切換 Bot、Alt+1～9 跳到側欄第幾個、Ctrl+, 設定、Ctrl+Shift+, 目前 Bot 的設定。
- **輸入框**：輸入 `/` 選擇技能，輸入 `@` 提到其他 Bot、群組或已連接的應用程式。
- **語音**：麥克風按鈕（Ctrl+D）用瀏覽器的語音辨識把話打進輸入框。輸入框空白時，耳機按鈕會開始「語音對話」：說完停一下就送出，Bot 回答後自動朗讀，再繼續聆聽，直到你結束。需要支援 Web Speech API 的瀏覽器（Chrome、Edge、Safari）。

## 技能、記憶與教學

- **技能**：在 Bot 設定的「技能」分頁管理。技能是 Hermes 實際讀取的 `SKILL.md`，可以新增、編輯、停用；Bot 學到新技能時會通知你。
- **技能清單與技能庫**：每次對話只會帶上「技能清單」裡每個技能的名稱與用途（完整步驟要用到才讀），頁面上方會顯示大約佔多少 token。30 天沒用過的 Hermes 內建技能（PDF、Excel、影片、論文搜尋等）會自動放進「技能庫」，平常不佔用；Bot 需要時用 `skill_library` 搜尋載入，用過就回到清單。每個技能都可以手動「放進技能庫」或「放回技能清單」；Bot 自己學到的技能一律留在清單。
- **重複的技能**：Bot 為同一件事寫了好幾個技能時，技能分頁會提示，按「請 Bot 合併」就會交給 Bot 合併成一個，避免做法互相矛盾。Bot 新增技能前也會先檢查有沒有相同用途的技能。
- **記憶**：Bot 設定的「記憶」分頁列出「關於你」與「Bot 記住的事」，可以修改、刪除與新增，並顯示 Hermes 的字數上限；修改從下一次對話生效。
- **教它一件事**：在 Bot 的電腦上親自示範一次。LazyBoy 會記下每一步對哪個元素做了什麼（例如「點擊按鈕『查詢』」），並附上截圖；密碼欄位只記成 ••••。過程中可以補充說明、暫停或刪掉做錯的步驟。完成後 Bot 會推論目的與參數，不確定時先問你，再用 Hermes 的 `skill_manage` 寫成技能，並預設自己試做一次。

## 連接應用程式

「設定 → 連接應用程式」提供 Notion、Jira 與 Confluence、Linear、GitHub、Figma、Canva、Dropbox、Todoist 等 60 多個服務，來源是 Hermes 內建的官方 MCP 清單。

- 選擇應用程式並按「登入並連接」，登入頁會在 Bot 的電腦上開啟並即時顯示；登入並授權後自動完成。也可以在自己的裝置登入，最後把停住的網址整串貼回來即可。
- 登入資料存放在 `.data/mcp-tokens/`，所有 Bot 共用，登入一次每個 Bot 都能使用。
- 不需要帳號的服務（Context7、DeepWiki、Microsoft Learn 等）按「連接」即可；GitHub 需要貼上 Personal Access Token。
- 已連接的應用程式會列出可用工具，每個工具都可以單獨關閉，讓 Bot 比較不會用錯工具，送給模型的工具說明也比較短。
- 清單外的服務可以在「自訂連接（MCP）」用網址或啟動指令加入；遠端服務可選擇「登入帳號（OAuth）」，並設定為共用或只給某個 Bot 使用。

## 定時任務

- 在對話標題列的「定時任務」管理，也可以請 Bot 自行建立。重複方式有單次、每天、平日、每週、每月，以及「每隔一段時間」（最短 5 分鐘）。「時間飄移」可以讓每次在設定時間後 15 到 120 分鐘內隨機執行，像真人發文。每個 Bot 最多 50 個定時任務。
- 清單顯示下次與上次執行的時間與結果；「執行紀錄」保留最近 20 次。無法開始時會在 1、5、15、60 分鐘後重試；服務離線期間錯過的任務，恢復後補做一次。
- **網址觸發**：選擇「只由網址觸發」或勾選「也可以用網址觸發」，會產生專屬網址。Slack、GitHub、表單等服務以 POST 呼叫它就會執行，送來的內容當成資料交給 Bot。同一個任務每分鐘最多觸發一次，網址可以隨時換新。外部服務必須能連到這台主機。
- 定時任務觸發的訊息在對話中以「定時任務」卡片呈現。
- 任務指示寫明要做的事，就算是你的授權：時間到 Bot 會直接做完並回報，不會每次停下來問。指示沒涵蓋的新決定（新對象、新商品或連結、花錢、刪除），或「先問我」勾選的動作，才送到「待你核定」。

## 分享、範本與登入

- **分享 Bot**：Bot 設定的「儲存並分享 Bot」會產生分享檔，包含角色、技能與去除秘密的 MCP 設定。匯入時建立新的獨立 Bot，不會複製聊天、記憶、API key 或瀏覽器登入。
- **範本**：在 Bot 上按右鍵「存成範本」，之後可以在「新增 → 你的範本」或側欄的「Bot 範本」一鍵建立同樣設定的 Bot。分享與範本只包含 Bot 自己的技能，未修改的 Hermes 內建技能不會重複打包。
- **分享登入**：在 Bot 上按右鍵「分享登入給其他 Bot」，勾選網站與要分享的 Bot，對方的瀏覽器就會有相同的登入。只複製勾選的網站，登入資料直接在兩台電腦之間傳送，不會顯示在畫面上。

## Context 與模型用量

- **Context 用量**：對話右上「⋯ → Context 用量」顯示這段對話佔用多少模型 context，並分成人設與系統說明、內建工具、應用程式工具、技能清單、記憶與對話紀錄。可以「壓縮舊對話」（保留最近的內容，較早的濃縮成摘要）或開新對話。不用手動管理：舊的大型工具輸出（網頁原始碼等）超過約 4.8 萬 token 會自動精簡（不花模型費用），整段對話超過約 10 萬 token 會自動壓縮成摘要，長期使用的 Bot 也不會越用越慢、越貴。
- **模型用量**：「設定 → 模型用量」依供應商與模型統計 token、請求次數、快取命中率與每日用量（7、30、90 天），包含背景子任務、對話壓縮與自動命名的請求。
- **Bot 用量**：Bot 設定的儲存空間區塊顯示該 Bot 最近 7 天的工作次數與 token 數，以及工作區、上傳、快取、瀏覽器各佔多少空間；「立即清理快取」會清掉暫存、瀏覽器快取與預覽快取，快取每天也會自動清理。

## 進階模型設定

- **進階設定**：API 介面、推理強度、讀取圖片、產生圖片與服務網址收在「進階設定」，通常不需要修改。讀取圖片依 Hermes 對模型的能力資料自動開啟；推理強度只列出模型支援的等級，未指定時使用 medium。
- **對話與工作分流**：「設定 → 模型 → 對話與工作分流」可以分別指定聊天、工作與備援模型，以及各自的推理強度與等待上限。工作開始使用工具時會升級到工作模型；遇到限流或連線失敗時依序改用備援模型（開始串流後不重送）。Bot 自己指定的模型優先。
- **語意路由（選用）**：`./scripts/routing.sh start` 會在本機 `8778` port 啟動 Semantic Router 分類服務（第一次啟動需下載並暖機模型）。就緒後可在分流的進階設定啟用；預設只記錄分類結果，取消該選項後才會採用高信心的分類。`./scripts/routing.sh stop` 停止服務。
- **網路搜尋**：預設使用 Exa 的免費額度。「設定 → 模型 → 網路搜尋」可改用 Tavily、Brave 或 DuckDuckGo 並填入 API key；填入 xAI API key 後，Bot 也能搜尋 X 貼文。
- **供應商清單**：內建清單存放在 `server/hermes_providers.json`，由 Bot 映像中的 Hermes 匯出。升級 Hermes 並重建映像後，執行 `make providers` 更新。

## 資料與備份

所有資料都在專案的 `.data/`（可用 `LAZYHERMES_DATA_DIR` 改變位置）：

| 路徑 | 內容 |
| --- | --- |
| `product.sqlite3` | Bot、對話、工作、定時任務等產品資料 |
| `settings.json` | 模型供應商設定與金鑰 |
| `access-token` | 其他裝置的登入碼 |
| `mcp-tokens/` | 已連接應用程式的登入資料（所有 Bot 共用） |
| `bots/<bot-id>/hermes/` | Hermes 設定、原生對話、記憶、技能與秘密設定 |
| `bots/<bot-id>/home/` | 桌面設定與 Chromium 的持久 profile（網站登入） |
| `bots/<bot-id>/workspace/` | 上傳的檔案與工作成果 |

- **備份**：先 `make stop`，再備份整個 `.data/` 目錄。
- **刪除**：刪除 Bot 會一併刪除它的電腦容器與資料。清除或刪除某個對話串只影響那一串，檔案、技能與登入都會保留。
- **自動清理**：每天清理 Hermes 的暫存檔、超過 200 MB 的瀏覽器快取，以及超過 30 天的附件。
